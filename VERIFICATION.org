#+TITLE: Verification
#+STARTUP: overview

Run everything with =emacs-sync.sh verify=. The script loads the config, runs
the checks and reports startup time. Exit status 0 means all checks passed.

* Gates

| Check | What it proves |
|-------+----------------|
| =stage1-check.el= | The eight workflow states, the exact removed-key list, the surviving bindings, and no capture template behind the node finder |
| =stage3-check.el= | A file ID becomes a node, a link becomes a backlink, and the index rebuilds from a temporary tree |
| =stage5-check.el= | A real EPUB opens in nov-mode and renders text for a terminal |
| =stage7-check.el= | Every live =C-c= binding is in the cheatsheet; no doc teaches a removed key; no config file still points into the old tree |

The earlier board, dashboard, capture and backup checks were removed with the
features they covered. The current gates do not write into =~/knowledge=.

* Why the key contract is checked twice

=stage1-check.el= holds the list of keys that must be unbound and the list that
must still resolve. =stage7-check.el= reads the cheatsheet and the tutorial and
checks the other direction: a document cannot teach a key that does nothing.
Both run in batch with the same =init.el= that Emacs loads.

* Known limits

- Python Eglot keys are bound but no Python language server is installed here.
  C and C++ have clangd.
- Files already under =~/projects= are outside this configuration. Their
  generated blocks are no longer refreshed from here.
- Org-roam's graph needs org-roam-ui, which is installed but only starts on
  request through =C-c k g=.
