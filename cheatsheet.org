#+STARTUP: overview

The key reference for this configuration. Every binding here was checked
against the running keymaps; the master table at the bottom is *generated* from
them, so it cannot drift.

Refresh that table after changing keys: =C-c k b= (or =C-c C-c= on the block).
Open the live version any time with =C-c ?=.

Architecture and reasoning: =ORG-PKM.org= (=C-c k H=).
Evidence that it all works: =VERIFICATION.org=.
Gates: =./emacs-sync.sh verify=.

* The knowledge layer (C-c k) — start here

This is what the configuration exists for. ~/knowledge/ holds the notes; Emacs
is the only editor expected to understand them.

** Making things

| Key       | Does                                              |
|-----------+---------------------------------------------------|
| =C-c k p= | new project: prompts a name, writes =notes/projects/<name>.org= with an ID, the workflow line, a Tasks section and a kanban block |
| =C-c k l= | new learning subject: same, in =notes/learning/=   |
| =C-c k n= | new permanent note: prompts for the area (artificial-intelligence, software-engineering, business, economics, productivity) then the title |
| =C-c k r= | new source note in =notes/references/=             |

Every created file refuses to overwrite an existing one, which is the point:
a typo in the name never destroys a file.

* The workflow: eight states

=BACKLOG(b) TODO(t) NEXT(n) DOING(o) WAITING(w) REVIEW(r) | DONE(d) CANCELLED(c)=

=C-c C-t= then the letter jumps straight to that state. =S-right= / =S-left= on
a heading cycles without the menu.

| State   | Means                                                    |
|---------+----------------------------------------------------------|
| BACKLOG | captured, not committed to. Never appears on a dashboard   |
| TODO    | committed, unscheduled                                     |
| NEXT    | the next physical action; a project with none is flagged   |
| DOING   | in progress now                                            |
| WAITING | blocked on someone else — and it blocks its subtasks       |
| REVIEW  | finished, needs a second look                              |
| DONE    | terminal; writes a =CLOSED:= timestamp in the =LOGBOOK=     |
| CANCELLED | terminal, off every board                                |

Recurring items use plain repeaters (=+1w=, =.+1d=, =++1m=). Dependencies use
parent/child plus the =ORDERED= property; =org-depend= is not used because
Emacs 31 no longer ships Org's contrib directory.

** Kanban

Boards are dynamic blocks, four of them: one per project, one per subject, plus
the consolidated ones in =dashboards/projects.org= and =dashboards/learning.org=.

Point on a row, press =C-c k m=, then:

| Key       | Does                                    |
|-----------+-----------------------------------------|
| =a= / =h= | move the task back one state            |
| =d= / =l= | move the task forward one state         |
| =w= / =k= | move the row up                         |
| =s= / =j= | move the row down                       |

The row is a link, not a copy: moving it runs =org-todo= on the heading in the
task's own file and saves that file. =CANCELLED= is not a column. A board is as
wide as its links — see =ORG-PKM.org= for the =:range= knob if seven columns
overflow your terminal.

** Structure and editing

| Key             | Does                                  |
|-----------------+---------------------------------------|
| =TAB= / =S-TAB= | fold / unfold subtree                 |
| =M-left/right=  | promote / demote heading              |
| =M-up/down=     | move subtree; with a region, move the line |
| =C-c C-s=       | schedule                              |
| =C-c C-d=       | deadline                              |
| =C-c C-w=       | refile                                |

=org-return-follows-link= is on, so RET on a link follows it.

be marked DONE and tells you why.

** Agenda

| Key       | Does                                              |
|-----------+---------------------------------------------------|

| =C-c k D=, =C-c k P=, =C-c k L= | the three dashboards                           |

=f= / =b= next/previous span, =g= refresh, =q= quit.

layer. Startup is ~0.15 s.

* Daily workflow

1. =C-c k D= — today, next actions, what is in progress, what is waiting.
2. Capture whatever interrupts you: =C-c k i= (inbox) or =C-c k t=.
3. Work a task: open its project file, or move it on =C-c k B=.
4. Learn something: =C-c k t= → =l= → subject; note the reusable idea with =C-c k n= and link it with =C-c k f=.
5. Read: =C-c k R= to see the queue, =C-c k A= to attach a book, =C-c k S= to move its status.
6. End of day: =C-c k t= → =j=.
7. Weekly: =C-c k b= to rebuild every board and dashboard, then read =C-c k d=.

* When it looks broken

| Symptom | Check |
|---|---|
| Emacs will not start | =emacs --batch -l ~/.emacs.d/init.el --eval '(princ "ok")'= |
| a key does nothing | =C-c ?= — absent means unbound; present means =C-h k= it |
| board is empty | the board derives columns from the files it scans; an empty tree has none |
| board is too wide | =:range (TODO . REVIEW)= on the =#+BEGIN: kanban= line |
| dashboard says "Nothing here" | the query is right and nothing matches; check the block's =:query= |
| roam finds nothing | =C-c k s=; the index is disposable, not precious |
