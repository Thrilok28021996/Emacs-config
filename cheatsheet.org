#+TITLE: Key cheatsheet
#+STARTUP: overview

This is the short version. =ORG-PKM.org= explains the layout and why the keys
are grouped this way; =VERIFICATION.org= records how the keymaps are checked.

* Where the prefixes lead

| Prefix | Use |
|--------+-----|
| =C-c k= | Zettelkasten: find, backlinks, sync, graph, help |
| =C-c o= | Org clocking and node insertion |
| =C-c c= | Compile, Python, Eglot, references |
| =C-c e= | Flymake diagnostics |
| =C-c g= | Magit |
| =C-c p= | Emacs projects (same map as =C-x p=) |
| =C-c v= | Conda environments |
| =C-c w= | Window navigation and layout |
| =C-c i= | Indentation |
| =C-c f= | Recent files |
| =C-c s= | Imenu |
| =C-c t= | Theme |

The old creation, capture, dashboard and reading-queue keys are gone. Notes in
=~/knowledge= are made by hand and numbered by hand.

* Zettelkasten, day to day

- =C-c k f= finds a node by title, or creates one.
- =C-c o i= inserts an =id:= link at point.
- =C-c k v= toggles the backlinks buffer for the current note.
- =C-c k s= rebuilds the index and reports node and link counts.
- =C-c k g= opens the graph in a browser when org-roam-ui is installed.
- =C-c k H= opens =ORG-PKM.org=.

The index lives in =~/.emacs.d/org-roam.db=. It is disposable: delete it and
=C-c k s= rebuilds it from the Org files.

* Org on a note

Clocking still works in any Org buffer.

| Key | Does |
|-----+------|
| =C-c o I= | Clock in |
| =C-c o O= | Clock out |
| =C-c o R= | Insert a clock report |

The eight states are =BACKLOG=, =TODO=, =NEXT=, =DOING=, =WAITING=, =REVIEW=,
=DONE= and =CANCELLED=. =C-c C-t= sets one from inside an Org buffer.

* Coding

- =C-c c c= compiles; =C-c c p= runs the current Python file with =python3=.
- =C-c c r=, =C-c c i= and =C-c c d= go through Eglot or xref.
- =C-c c a= lists code actions; =C-c c f= formats the buffer; =C-c c h= toggles inlay hints.
- =C-c e n=, =C-c e p= and =C-c e b= walk Flymake diagnostics.
- =C-c g g= opens Magit status. The other =C-c g= keys are commit, push, pull,
  fetch, log, diff, branch, blame and stash.
- =C-c p f= finds a file in the current project; =C-c p p= switches project.

Python diagnostics need a language server on =PATH=. None is installed here,
so those bindings stay but have nothing to talk to in Python buffers.

* Windows and buffers

| Key | Does |
|-----+------|

| =C-c s i= | Imenu |
| =C-c w h= / =C-c w j= / =C-c w k= / =C-c w l= | Window left / down / up / right |
| =C-c w u= / =C-c w U= | Undo / redo window layout |
| =C-c w == | Balance windows |
| =M-o= | Next window |
| =C-x C-/= | Redo |

* Environment and look

- =C-c v a= activates a Conda environment; =C-c v d= deactivates it.
- =C-c t t= toggles dark and light themes.
- =.epub= files open in nov-mode, so EPUB text is readable in a terminal.

* When a key seems wrong

Use =C-h k= then the key. If it is absent from this sheet, it is not part of
the configuration any more.
