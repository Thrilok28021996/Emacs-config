Concept node structure:
- * What — definition
- * Why — reason it matters
- * When — when to use it
- * Code — example
- * Links — related nodes

Question node structure:
- * Question
- * Answer
- * Related Concepts

** Spaced Repetition (SRS)
1. Capture item with =SPC n v= (Review template)
2. Item gets REVIEW state + scheduled date
3. On review day: open agenda =SPC n a=
4. After recall: =SPC n d= (marks reviewed, schedules next)

Intervals: 1 → 3 → 7 → 14 → 30 → 60 days → MASTERED

* AI Assistant (gptel + LM Studio)
| Key       | Action              |
|-----------+---------------------|
| SPC a c   | open AI chat        |
| SPC a s   | send to AI          |
| SPC a r   | AI rewrite          |
| SPC a m   | AI menu             |

Start a chat: =SPC a c= opens gptel buffer. Write your prompt, =SPC a s= sends.
Works in any buffer — select text, =SPC a r= to rewrite it.

* Completion
- =corfu= — inline completion popup (auto after 2 chars)
- =TAB= — accept completion
- =M-n / M-p= — next / prev candidate
- =vertico= — minibuffer completion (file find, M-x, etc.)
- =orderless= — fuzzy matching: type any words in any order

* Workflow — Daily Use
1. Start day: =SPC o a= → check agenda (scheduled tasks, reviews due)
2. Capture anything: =SPC o c= → pick template
3. Work task comes up: =SPC n w= → captured to work/tasks.org
4. Learn something: =SPC n k= → concept node in roam
5. Question arises: =SPC n q= → question node
6. End of day: =SPC n j= → journal entry (worked on, notes, reading)
7. Weekly: fill out reviews.org weekly section
