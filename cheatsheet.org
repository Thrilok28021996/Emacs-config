** Search
| Key       | Action                          |
|-----------+---------------------------------|
| C-s       | search buffer (consult-line)    |
| C-c s s   | search buffer                   |
| C-c s r   | ripgrep project                 |
| C-c s i   | jump to symbol (imenu)          |

Tip: =C-s= shows ="3 of 12"= match count automatically (=isearch-lazy-count=).

*** wgrep — edit ripgrep results
1. =C-c s r= → run ripgrep
2. =C-.= → =e= to enter wgrep mode (all matches become editable)
3. Edit any line directly
4. =C-c C-c= → write all changes back to their files
5. =C-c C-k= → abort without saving

** How to Use Each System

*** Agenda
The agenda pulls TODO/scheduled items from all files in =org-agenda-files=.

1. =C-c o a= → open agenda (day view by default)
2. Navigate days with =f= (forward) / =b= (backward)
3. On any item: =t= cycle state, =s= schedule, =d= deadline, =r= refile, =q= quit
4. Press =v w= for week view, =v m= for month view

Tip: agenda shows only items with a date or active TODO. Undated TODOs live in =C-x b tasks.org=.

*** Capture → Refile
Capture = quick drop into inbox. Refile = move to the right place later.

1. =C-c o c= (or shortcut) → pick template → write → =C-c C-c= to save
2. Items land in their target file (inbox, tasks, journal, etc.)
3. To refile: open the item, =C-c C-w= → pick destination heading
4. Refile targets = all files in =org-agenda-files= up to 3 levels deep

*** Org-Roam (knowledge graph)
Each note is a node. Nodes link to each other — backlinks show what points at the current node.

| Action                     | Key / Command          |
|----------------------------+------------------------|
| Find or create a node      | =C-c o r=              |
| Insert a link to a node    | =C-c o i=              |
| New concept node           | =C-c n k=              |
| New question node          | =C-c n q=              |
| New person node            | =C-c n P=              |
| See backlinks (what links here) | =M-x org-roam-buffer-toggle= |
| Search all nodes           | =C-c o s=              |

Workflow: write a note → link related nodes with =C-c o i= → backlinks panel shows connections automatically.

*** Roam UI (visual graph)
Launches a browser-based interactive graph of all your nodes.

1. =C-c o u= → opens browser tab with live graph
2. Click any node to open it in Emacs
3. Graph updates on save (=org-roam-ui-update-on-save t=)
4. Theme syncs with doom-one automatically

*** People (relationship tracking)
1. =C-c n P= → create person node (name, where they post, area: career/tech/drawing)
2. Fill in =* Who=, =* Find Them= (handle/link), =* Follow-up= (next action)
3. After any exchange → =C-c n x= → pick person → type what happened
4. =C-c o r= to find anyone by name
5. Follow-up checkboxes stay visible in the file — check when done with =C-c C-c=

*** Spaced Repetition (SRS)
1. Capture with =C-c n v=
2. Item gets REVIEW state + scheduled date
3. On review day: =C-c n a= → open review agenda
4. After recall: =C-c n d= → schedules next interval

Intervals: 1 → 3 → 7 → 14 → 30 → 60 days → MASTERED

*** Pomodoro
Work in focused 25-minute blocks, tracked per org heading.

1. Go to any task heading in an org file
2. =M-x org-pomodoro= → starts 25-min timer, logs time to the heading
3. Bell rings at end → short break auto-starts
4. Clock time visible in agenda and modeline

*** Transclusion
Include live content from another node — changes in source reflect everywhere it's transcluded.

1. =C-c o t= → toggle transclusion mode in current buffer
2. =C-c t a= (in org-mode) → add a transclusion at point — prompts for source node
3. Content appears inline; edit the source file to update it everywhere
4. Toggle off with =C-c o t= to see raw =#+transclude= links

*** Paste Image (org-download)
1. Copy an image to clipboard (screenshot, browser, etc.)
2. =C-c o y= → image saved to =garden/images/= and link inserted at point
3. Image previews inline if =org-toggle-inline-images= is on (=C-c C-x C-v=)

*** Paste URL as Link (org-cliplink)
1. Copy a URL to clipboard
2. =C-c o l= → fetches page title, inserts =[[url][Page Title]]= at point

*** Deft (quick search)
Full-text search across all garden files. Faster than roam for fuzzy recall.

1. =C-c o d= → opens deft buffer with live filter
2. Type any word → results narrow in real time
3. =RET= to open, =C-c C-n= to create a new roam node from the search term
4. =C-g= to quit

*** Org-Babel (run code in notes)
Execute code blocks inside org files. Results insert below the block.

1. In any org file, create a block: =<s TAB= → expands to =#+begin_src=
2. Specify language: =#+begin_src python=
3. =C-c C-c= inside the block → runs it, inserts =#+RESULTS:= below
4. Supported: python, shell, emacs-lisp (configured in your setup)

*** Super Agenda (agenda grouping)
=org-super-agenda-mode= is active — groups agenda items by category automatically.
No extra keys needed; configure grouping in =org-super-agenda-groups= if you want custom sections.

* Workflow — Daily Use
1. Start day: =C-c o a= → check agenda
2. Capture anything: =C-c o c= → pick template
3. Work task: =C-c n w= → work/tasks.org
4. Learn something: =C-c n k= → concept node in roam
5. Question arises: =C-c n q= → question node
6. End of day: =C-c n j= → journal entry
7. Weekly: fill out reviews.org weekly section
