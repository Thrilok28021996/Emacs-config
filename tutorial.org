#+TITLE: Tutorial
#+STARTUP: overview

A short tour of what the keyboard actually does now. =cheatsheet.org= lists
every binding; =ORG-PKM.org= explains the layout; =VERIFICATION.org= has the
gates.

* Find a note

1. =C-c k f= opens the node finder over =~/knowledge=. Pick a note that
   already exists; it does not create files.
2. =C-c o i= inserts an =id:= link at point. Use it when one note refers to another.
3. =C-c k v= toggles the backlinks buffer while point is in a note.
4. =C-c k s= rebuilds the index. The database is disposable, so this is safe.
5. =C-c k g= opens the graph if org-roam-ui is installed.

Notes are created and numbered by hand. There is no capture template for them.

* Clocking

In any Org buffer:

| Key | Does |
|-----+------|
| =C-c o I= | Clock in on the entry at point |
| =C-c o O= | Clock out |
| =C-c o R= | Insert a clock report |

* Working on code

- =C-c p f= finds a file in the current project; =C-c p p= switches project.
  The whole =C-c p= map is the same one bound to =C-x p=.
- =C-c c c= compiles. =C-c c p= runs the current Python file.
- =C-c c r= renames a symbol; =C-c c i= finds implementations;
  =C-c c d= finds references; =C-c c a= opens code actions.
- =C-c c f= formats the buffer; =C-c c h= toggles inlay hints.
- =C-c e n= and =C-c e p= step through diagnostics; =C-c e b= lists them.
- =C-c g g= opens Magit. From there use Magit's own single-letter keys.

Eglot needs a language server. C and C++ have clangd here; Python does not.

* Windows, files and buffers

- =C-c f r= opens recent files.
- =C-c s i= jumps to an imenu entry in the current buffer.
- =C-c w h=, =C-c w j=, =C-c w k= and =C-c w l= move between windows.
- =C-c w u= and =C-c w U= undo and redo window layouts; =C-c w == balances them.
- =M-o= selects the next window; =C-x C-/= redoes the last edit.

* Small conveniences

- =C-c v a= activates a Conda environment; =C-c v d= deactivates it.
- =C-c t t= switches between dark and light themes.
- =C-c i r= and =C-c i l= shift a region by one tab stop.
- =C-c k H= opens the architecture document from any buffer.

* Check yourself

Run =emacs-sync.sh verify= from the config directory. The checks confirm that
every key in the cheatsheet resolves and that no removed key is still taught.
If a key here stops working, =C-h k= followed by the key is the fastest way to
see what changed.
