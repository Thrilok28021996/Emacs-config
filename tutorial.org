#+TITLE: Org Mode Tutorial — Your Setup, End to End
#+AUTHOR: Thrilok
#+STARTUP: overview

This is a *hands-on* learning path for the Org setup in your =init.el=. Every
lesson uses your real keybindings and your real files (=~/Documents/garden/=).
Do the "▶ Do this now" steps in order — the point is muscle memory, not reading.

Pair this with =cheatsheet.org= (=C-x C-f ~/.emacs.d/cheatsheet.org=): tutorial
teaches the flow, cheatsheet is the lookup card once you know what you want.

Suggested pace: one lesson a day for ~2 weeks. By the end the keys are reflex.

* Lesson 0 — Orientation (5 min)
*What Org is:* plain-text =.org= files that fold into outlines. Headings start
with =*=. Everything else (agenda, roam, capture) is built on that one idea.

*Your file layout* (all under =~/Documents/garden/=):
| File                  | What lives here                       |
|-----------------------+---------------------------------------|
| inbox.org             | quick capture dump — sort later       |
| journal.org           | daily log (datetree)                  |
| reading.org           | books + reading notes                 |
| reviews.org           | spaced-repetition items               |
| work/tasks.org        | work next actions                     |
| work/projects.org     | work project index                    |
| personal/tasks.org    | personal next actions                 |
| personal/projects.org | personal project index                |
| (any) *_archive       | archived/done items, out of agenda    |

▶ Do this now: =C-c o r= (roam find) — type any word, hit RET on "create". You
just made your first node. =C-x C-f ~/Documents/garden/= to see your files.

* Lesson 1 — Structure: headings, folding, lists, links (15 min)
The whole editor is an outline. Master folding and movement first.

| Key       | Action                      |
|-----------+-----------------------------|
| M-RET     | new heading at same level   |
| TAB       | fold / unfold this heading  |
| S-TAB     | fold / unfold whole file    |
| M-LEFT/RIGHT | promote / demote heading |
| M-UP/DOWN | move subtree up / down      |
| C-c C-n/p | next / previous heading     |

Lists: start a line with =-= or =1.=. =M-RET= makes the next item. =C-c C-c= on
a =[ ]= checkbox toggles it.

Links: =C-c C-l= insert a link, =C-c C-o= open the link under cursor.

▶ Do this now: open =inbox.org=, =M-RET=, type =* Practice=, =TAB= to fold/unfold,
=M-RET= again for a sub-item, add a =- [ ] test= checkbox, =C-c C-c= to tick it.

* Lesson 2 — TODO states & the agenda (the GTD core) (20 min)
A heading becomes a task when it starts with a TODO keyword. =C-c C-t= cycles it.

*Your two TODO workflows:*
- General: =TODO → NEXT → DONE=  (NEXT = "the thing I'll actually do next")
- Learning: =NEW → LEARNING → REVIEW → APPLY → MASTERED= (or =DROPPED=)

*The agenda* pulls every dated/TODO item from your agenda files into one view.

| Key       | Action                      |
|-----------+-----------------------------|
| C-c o a   | open agenda dispatcher      |
| C-c o a → a | day/week agenda           |
| C-c o a → d | your Dashboard (see L12)   |
| (in agenda) t | cycle TODO              |
| (in agenda) s / d | schedule / deadline |
| (in agenda) f / b | next / prev day     |
| (in agenda) q | quit                    |

▶ Do this now: in =work/tasks.org= add =* TODO Try the agenda=, =C-c C-t= to set
=NEXT=, then =C-c o a → a=. See it appear. Press =t= on it to mark DONE.

* Lesson 3 — Capture → Refile (don't break flow) (20 min)
*Capture* = drop a thought in 5 seconds without leaving what you're doing.
*Refile* = move it to its real home later.

Your capture keys (each opens a template, write, then =C-c C-c= to file it):
| Key     | Captures to                  |
|---------+------------------------------|
| C-c n i | inbox                        |
| C-c n j | journal entry (today)        |
| C-c n w | work task                    |
| C-c n t | personal task                |
| C-c n r | reading note                 |
| C-c n v | review item (SRS)            |

Refile: on any heading, =C-c C-w= → pick a destination (any heading in your
agenda files, up to 3 levels deep).

▶ Do this now: =C-c n i=, type =Buy a notebook=, =C-c C-c=. Open =inbox.org=,
put cursor on it, =C-c C-w=, refile it into =personal/tasks.org=.

Habit to build: capture all day into inbox → once a day, refile the inbox to zero.

* Lesson 4 — Scheduling, deadlines, habits, archiving (15 min)
| Key     | Action                                  |
|---------+-----------------------------------------|
| C-c C-s | SCHEDULED — "start working on date"     |
| C-c C-d | DEADLINE — "must be done by date"       |
| C-c o A | archive this subtree (out of agenda)    |

*Scheduled vs Deadline:* scheduled = when it appears on your plate; deadline =
the hard date (agenda warns you in advance).

*Habits:* give a repeating task =:PROPERTIES: :STYLE: habit :END:= and a
=SCHEDULED= with a repeater like =.+1d=. The agenda draws a consistency graph.

*Archiving (hygiene):* DONE/MASTERED/DROPPED items pile up and slow things down.
=C-c o A= moves a finished subtree to =<file>_archive= — gone from agenda, still
on disk. Do this weekly.

▶ Do this now: schedule a task for tomorrow (=C-c C-s=, type =+1=), mark another
DONE and =C-c o A= to archive it. Check it left the agenda.

* Lesson 5 — Org-Roam: your knowledge graph (30 min)
Every note is a *node*. Nodes link to each other; *backlinks* show what points
at the current note. This is your "second brain".

| Key     | Action                         |
|---------+--------------------------------|
| C-c o r | find or create a node          |
| C-c o i | insert a link to another node  |
| C-c o s | search all nodes               |
| C-c o u | open the visual graph (browser)|
| C-c n k | new *concept* node             |
| C-c n q | new *question* node            |

Workflow: write a note → wherever you mention a related idea, =C-c o i= to link
it → the backlink panel (=M-x org-roam-buffer-toggle=) shows connections grow.

▶ Do this now: =C-c n k=, title "Python decorators", fill =What/Why/When=. Then
=C-c n k= again "Higher-order functions". In the first note, =C-c o i= and link
to the second. Open =C-c o u= to see them connected in the graph.

* Lesson 6 — People tracking (15 min)
Person nodes are roam notes tagged =:person:= with interaction logs.

| Key     | Action                                |
|---------+---------------------------------------|
| C-c n P | create a person node                  |
| C-c n x | log an interaction with a person      |
| C-c o r | find a person by name                 |

▶ Do this now: =C-c n P=, name someone, fill =* Who= and =* Find Them=. Later
=C-c n x=, pick them, type what you talked about — it timestamps under
=* Interactions= automatically. Add a =* Follow-up= checkbox and tick it with
=C-c C-c= when done.

* Lesson 7 — Spaced repetition (remember what you learn) (15 min)
Your homemade SRS: items get =REVIEW= state + a scheduled date. You review on
the due date and reschedule at growing intervals.

Intervals: =1 → 3 → 7 → 14 → 30 → 60 days → MASTERED=

| Key     | Action                          |
|---------+---------------------------------|
| C-c n v | capture a review item           |
| C-c n a | open the review agenda (today's)|
| C-c n d | mark reviewed → schedule next   |

▶ Do this now: =C-c n v=, "What does org-refile do?", =C-c C-c=. Tomorrow (or
edit its date to today): =C-c n a= to see it, recall the answer, =C-c n d= to
push it to the next interval.

* Lesson 8 — Reading workflow (10 min)
=reading.org= holds books/resources with a start page and rolling insights.

| Key     | Action                          |
|---------+---------------------------------|
| C-c n r | new reading note (prompts book) |

▶ Do this now: =C-c n r=, enter a book + start page, write one insight under
=** Insights=, =C-c C-c=. As you read more, open the note and append insights.

* Lesson 9 — Time tracking: clock + pomodoro (15 min)
*Clock* logs real time against a heading. *Pomodoro* runs focused 25-min blocks.

| Key     | Action                          |
|---------+---------------------------------|
| C-c o I | clock in (start timer on heading)|
| C-c o O | clock out                       |
| C-c o R | insert a clock report table     |
| C-c o e | set an effort estimate          |

Pomodoro: cursor on a task heading → =M-x org-pomodoro= → 25-min timer, auto
break, time logged to the heading.

▶ Do this now: on any task, =C-c o I=, do something for a minute, =C-c o O=.
Then =C-c o R= to see a time report table appear.

* Lesson 10 — Tables (10 min)
Org has a full spreadsheet in plain text.

Type a line starting with =|=, press =TAB= — it becomes a table and keeps
aligning as you go. =C-c -= inserts a header separator line.

| Key       | Action                  |
|-----------+-------------------------|
| TAB       | next cell (new row at end)|
| C-c C-c   | realign                 |
| C-c ^     | sort column             |
| M-LEFT/RIGHT | move column          |
| M-UP/DOWN | move row                |

Formulas: a column can compute. =:= field formula, =C-c == to enter one, e.g.
=$3=$1*$2= then =C-c C-c=.

▶ Do this now: type =| Item | Qty | Price |=, =TAB=, =C-c -=, fill two rows, and
=C-c ^= to sort.

* Lesson 11 — Org-Babel: run code in your notes (15 min)
Execute code blocks inline. Your setup runs =python=, =shell=, =emacs-lisp=.

Create a block (=<s TAB= expands a skeleton, or type it):
#+begin_example
,#+begin_src python
print(2 + 2)
,#+end_src
#+end_example

Put the cursor inside, =C-c C-c= → runs it, inserts =#+RESULTS:= below.

▶ Do this now: in any roam concept note, make a python block that prints
something, =C-c C-c=, watch the result appear. (Confirmation is off in your
config, so it just runs.)

* Lesson 12 — Power views: dashboard, super-agenda, org-ql, kanban (20 min)
*Dashboard* (your custom command): =C-c o a → d= = today's agenda + Next Actions
+ items Due for Review, in one screen. This is your morning view.

*Super-agenda* is always on — it auto-groups the agenda (Overdue / Today / Next
Actions / Learning / Work / Personal / Inbox). No keys needed.

*Org-QL* — ad-hoc queries sharper than dates:
| Key     | Action                            |
|---------+-----------------------------------|
| C-c o q | live-filter headings by text      |

=M-x org-ql-search= for query syntax, e.g. =(and (todo "NEXT") (tags "work"))=
or =(deadline :to today)=.

*Org-Kanban* — a board from your TODO states:
| Key     | Action                              |
|---------+-------------------------------------|
| C-c o k | insert a kanban block at point      |

=C-c C-c= on the block refreshes it; =M-x org-kanban/shift= moves a card (changes
its TODO state).

▶ Do this now: =C-c o a → d= and read your dashboard. Then =C-c o q=, type a word
that's in one of your tasks, and watch it filter live.

* Lesson 13 — Links to the outside: images, URLs, transclusion, export (15 min)
| Key     | Action                                   |
|---------+------------------------------------------|
| C-c o y | paste clipboard image into the note      |
| C-c o l | paste a URL as =[[url][Page Title]]=      |
| C-c o t | toggle transclusion (embed another node) |
| C-c C-x C-v | toggle inline image preview          |
| C-c C-e | export menu                              |

*Transclusion:* embed live content from another node — edit the source, it
updates everywhere. =C-c o t= to toggle the mode, then add a transclusion.

*Export:* =C-c C-e= → pick a backend. HTML (=h h=) and plain text work out of the
box. PDF needs a LaTeX install (you don't have one yet) — for sharing, export to
HTML or copy as Markdown instead.

▶ Do this now: copy a URL, =C-c o l= in a note. Take a screenshot, =C-c o y=.
Then =C-c C-e h o= to export the note to HTML and open it in a browser.

* Your 2-Week Ramp
1. *Days 1–2:* Lessons 0–2. Live in headings + the agenda. Make 5 real tasks.
2. *Days 3–4:* Lessons 3–4. Capture everything to inbox; refile to zero daily.
3. *Days 5–7:* Lessons 5–6. Start your roam graph; add concept notes as you learn.
4. *Days 8–9:* Lessons 7–8. Turn 3 things you learned into SRS review items.
5. *Days 10–11:* Lessons 9–11. Clock your work; run a code block in a note.
6. *Days 12–14:* Lessons 12–13. Make the dashboard your morning ritual; export one note.

The one habit that makes it stick: *=C-c o a → d= every morning, capture to inbox
all day, refile + archive once at night.* Everything else is detail.
